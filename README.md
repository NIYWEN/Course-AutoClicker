 # 自动刷课/挂机和防挂机助手 

因为实在受不了网课那每隔五分钟就弹一次的弹窗，索性写个脚本让它替我上课。代码可能很烂，但跑起来是真的爽。（但是本代码基于弹窗位置固定的课程，如果未来有需要我可能接着研究弹窗不固定的代码）。

### 这玩意儿能干嘛？

- **自动识别并点击**：不管是“继续播放”、“确认签到”还是各种奇奇怪怪的弹窗，只要截个图，记录弹窗按钮位置，它就能通过图像识别帮你点掉。
- **全自动无缝跳转**：读取 `urls.txt` 里的网址列表，当前视频播完（识别到结束画面）后，自动按 `Ctrl+L` 粘贴下一个网址并回车跳转。
- **拟人化防检测**：点击坐标自带 `random` 随机偏移，点完鼠标自动归位，防止遮挡视频画面，也防止被平台判定为机器人。
- **防崩溃机制**：找图失败不会报错闪退，如果卡死还可以按 `Ctrl+C` 或者把鼠标甩到屏幕左上角紧急制动。

### 怎么用？（保姆级教程）

1. **安装依赖库**（需要 Python 环境）：

```bash
  pip install pyautogui opencv-python pyperclip
```

2. **准备材料**：

- 把你要刷的视频网址，一行一个复制到 `urls.txt` 文件里（记得去掉 `#` 及后面的东西）。
   自己动手，用截图工具截取网页上各种弹窗的特征图，存为 `start.png`、`submit.png`、`end.png` 等。

- 运行

  ```bash
  python auto_course.py
  ```

  *(注意：运行后请迅速切回浏览器，不要挡住网页，不然图像识别会瞎掉。)*

### 踩坑与牢骚（开发笔记）

- **反爬拦截**：这个网站的开发者工具居然防调试，一打开 F12 就给我踢回主页。于是直接手动扒 URL 物理绕过。
- **识别精度**：截图千万别截太大的背景，只截特征最明显的字或者按钮，不然视频背景一变，`confidence=0.7` 也容易出问题。
- **关于 AI**：本来想让 AI 写，但想了想，大二还是得多自己练一练。哪怕写出 Bug 自己 Debug 一晚上，也比复制粘贴强。索性自己花了两天晚上一边看相关书籍，一边写代码，最后也是整出来了，还是很有成就感的。
